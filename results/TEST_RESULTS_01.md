## Purpose

To determine whether the core Datafructus process can recover a
hidden pattern from noisy data, compress it without losing meaning,
and reconstruct portions that were destroyed.

- Added random noise on top of the pattern
- Ran the core loop: Absorption, Pattern Recognition, Compression,
  Emission, Reconstruction
- Measured correlation between recovered and true hidden pattern
